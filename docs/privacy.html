Политика конфиденциальности

Приложение: «Моя учёба» (com.calculatorplatform.mylearn)

Дата: 2 сентября 2026

1. Общие положения

«Моя учёба» — офлайн-first приложение для учёбы. Основные данные (расписание, задания, оценки, посещаемость, фото заданий, история фокус-сессий) хранятся локально на вашем устройстве в SQLite и файловой системе приложения.

2. Какие данные обрабатываются

  • Расписание, предметы, преподаватели, учебные периоды
  • Задания, сроки, заметки, фото заданий
  • Оценки, посещаемость, цели по предметам
  • История учебных фокус-сессий
  • Намерения локальных напоминаний о заданиях
  • Резервные копии, создаваемые пользователем вручную

3. Локальные уведомления

Приложение может планировать локальные уведомления о заданиях и завершении фокус-сессии. Разрешение запрашивается только при явном действии пользователя.

4. Аналитика (AppMetrica)

Мы используем Yandex AppMetrica для агрегированной аналитики использования приложения. Передаются события (например, создание задания, завершение фокус-сессии) и технические параметры без текста заданий, имён предметов, заметок, путей к файлам и фото.

5. Реклама (Yandex Mobile Ads)

В приложении может показываться реклама Yandex. SDK может использовать advertising ID (Google Advertising ID) для подбора объявлений. Реклама при запуске приложения (App Open) не используется.

6. Резервное копирование и экспорт

Резервные копии и экспорт создаются по инициативе пользователя. Файлы передаются через системный диалог «Поделиться» на выбранное вами приложение или хранилище.

7. Передача данных третьим лицам

Данные учёбы не передаются на наши серверы автоматически. AppMetrica и Yandex Ads получают только данные, необходимые для работы соответствующих SDK, в соответствии с политиками Yandex.

8. Безопасность

Резервные копии и импортируемые файлы считаются недоверенными и проходят валидацию перед восстановлением. Пользователь несёт ответственность за хранение экспортированных файлов.
